# Support

Read the [quickstart](README.md) and [learning guide](docs/learning-guide.md) first.
For a reproducible issue, include a synthetic example, the suite/candidate, and
the command or browser steps. Once published, use the repository's issue tracker.

A failing score can be the intended result. The baselines intentionally contain
mistakes, and the holdout set exposes remaining weaknesses.

The project is an educational starter with no support SLA or claim of production
readiness.
