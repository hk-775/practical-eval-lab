GRADING SETTINGS

Changing the passing threshold changes the gate, not the score. Changing expected answers or grading rules changes the test itself.

What to notice

The bundled candidates are deterministic rules. Editing an eval does not train them. Registered candidates run your application; direct OpenAI runs use the command line.
